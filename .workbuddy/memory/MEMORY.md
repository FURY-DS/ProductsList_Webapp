# ProductsList_Webapp - 프로젝트 장기 노트

## 프로젝트 개요
- 한국 이커머스 상품 관리 웹앱 (vanilla HTML/CSS/JS, 외부 라이브러리 없음)
- file:// 로 직접 실행 가능, 빌드 불필요
- localStorage 기반 데이터 저장

## 사용자 (DS)
- 한국 거주, 중국 광저우 분할 체류
- 중국 수입 상품 관리 → 위안화(¥) 원가 / 원화(₩) 환율 표기
- 주로 PC 사용

## 페이지 구성 (11개 메뉴, 11개 활성)
1. **상품리스트** (index.html) - 핵심 마스터 페이지, 원가×환율×퍼센트=총합 자동계산
2. **N배송** (nshipping.html) - 단품/복수품, NY바코드/피킹/태그 비용 추가
3. **로켓그로스** (rocketgrowth.html) - N배송에서 3개 비용 필드 제거, 공식 상이
4. **스마트스토어** (smartstore.html) - 단품/복수품, 판매수수료/최종이익 계산
5. **쿠팡** (coupang.html) - 스마트스토어와 100% 동일
6. **ESM** (esm.html) - 스마트스토어와 100% 동일
7. **11번가** (elevenst.html) - 스마트스토어와 100% 동일
8. **오너클랜** (ownerclan.html) - 공급가입력 필드 추가, 판매가=공급가×1.1 자동계산, 수식 상이 (스마트스토어와 동일 구조이지만 계산 다름)
9. **도매꾹** (domagguk.html) - 스마트스토어와 100% 동일
10. **올웨이즈** (always.html) - 스마트스토어와 100% 동일
11. **토스쇼핑** (tossshopping.html) - 스마트스토어와 100% 동일

## 기술 구조
- SRP 모듈 분리: 각 페이지마다 config/state/storage/search/card/actions/app 7개 JS 모듈
- 공유 CSS: css/base.css + css/card-features.css (상품리스트도 동일)
- 크로스 페이지 연동: 상품리스트 코드 변경 시 다른 페이지 최종원가 자동 재계산 (storage 이벤트)
- 내보내기/가져오기: 페이지 검증 + 호환 그룹(smartstore/coupang/esm/elevenst/ownerclan/domagguk/always/tossshopping 8개 상호 호환)
- 이미지: base64 localStorage 저장, canvas 리사이즈(800px, JPEG 0.8), 용량 초과 시 이미지 제거 저장
- escapeAttr: 모든 필드 + 이미지 src에 XSS 방지 이스케이프 적용
- save 함수: 결과 객체 반환 패턴 ({ ok, imagesRemoved, msg })
  - save 계열은 토스트를 직접 띄우지 않음. **모든 호출부는 반드시 utils.js의
    reportSaveResult(result, CONFIG.MESSAGES, 성공메시지?)로 결과를 전달해야 함**
    (성공메시지 생략 시 성공은 조용히, 실패만 알림). 새 페이지 추가 시 이 규칙 유지할 것
