- 원인: 쿠팡 카드의 className이 `'card coupang-card'`만 가지고 있고, css/smartstore.css의 모든
  디자인 선택자가 `.smartstore-card`로 시작해서 쿠팡에는 적용 안 됨
  (예: `.smartstore-card .fee-field .fee-rate { width: 70px }`가 미적용)
- 수정: js/coupang-card.js의 `renderCoupangCard()`에서
  `wrap.className = 'card coupang-card smartstore-card'`로 변경
  → coupang-card는 식별용, smartstore-card는 디자인 적용용으로 이중 클래스
  → syncCoupangCardFromDOM()의 `.smartstore-card[data-id=...]` 쿼리도 자동으로 매칭됨
- 효과: 판매수수료 옆 비율 입력 칸(70px)과 그 아래 자동 계산 박스가 N배송과 동일하게 작게 표시됨
- 참고: 이 패턴은 다른 새 페이지를 만들 때도 동일하게 적용 가능
  (smartstore.css를 공유할 거면 반드시 `smartstore-card` 클래스 추가)
