## v46 - 오픈마켓정산 연도 전환 시 데이터 삭제 버그 수정 (2026-07-28 19:42)
- 요청: 2026년 데이터 입력 후 2025/2024년으로 전환했다가 돌아오면 데이터가 전부 삭제되는 치명적 버그
- 원인:
  - storage가 단일 키(settlement_v1)에 1년치 데이터만 저장 { year, months }
  - changeSettlementYear에서 연도별 키(settlement_v1_YYYY) 사용하지만 initEmptySettlement()가 year를 현재 연도로 덮어쓰는 버그
  - 그 결과 빈 months가 메인 키와 연도별 키 모두를 덮어써서 데이터 완전 소실
- 해결: 다년도 저장 구조로 전면 재설계 (storage version 2)
  - 새 형식: { version: 2, currentYear: 2026, years: { "2026": {months}, "2025": {months} } }
  - saveSettlement(): 현재 연도 months를 years[currentYear]에만 업데이트 (타 연도 영향 없음)
  - loadSettlement(): storage에서 currentYear의 months 로드, 구버전 자동 마이그레이션
  - changeSettlementYear(): 현재 데이터 저장 → 연도 전환 → 해당 연도 데이터 로드 (없으면 빈 months)
  - loadYearData(year): 특정 연도 months 반환 (없으면 null)
  - initEmptyMonths(): year를 변경하지 않고 빈 months만 생성 (핵심 수정)
  - 구버전 마이그레이션: { year, months } → v2 변환 + 연도별 키(settlement_v1_YYYY) 통합 + 구키 정리
  - clearSettlement: 전체 초기화 → 현재 연도만 초기화로 변경 (메시지도 동적 연도 표시)
  - importSettlement: 가져오기 후 year select 동기화 추가
- 파일:
  - js/settlement-storage.js: 전면 재작성
  - js/settlement-actions.js: changeSettlementYear, clearSettlement, importSettlement 수정
- 테스트: syntax check 통과
